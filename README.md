# Projeto Backend – API de Artistas e Álbuns

## 📌 Descrição
API REST desenvolvida em Spring Boot para gerenciamento de artistas e álbuns musicais, com relacionamento muitos-para-muitos entre artistas e álbuns.

Projeto desenvolvido como parte de avaliação técnica conforme edital, com foco em organização, boas práticas e funcionamento da API.

---

## 🛠 Tecnologias Utilizadas
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- Banco de dados H2 (em memória)
- Flyway (versionamento de banco)
- Maven
